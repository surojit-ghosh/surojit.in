Personal portfolio at [surojit.in](https://surojit.in). File-based MDX projects, typed experience/education data, theme toggle, and a server-fetched GitHub contributions graph.

## Highlights

- MDX frontmatter pipeline (`getProjects` / `getDetailsBySlug`) for listing and detail pages
- Edge Open Graph image route; metadata for social sharing
- GitHub contributions via external API with daily revalidation
- shadcn/ui + Tailwind layout: hero, featured projects, experience, education
