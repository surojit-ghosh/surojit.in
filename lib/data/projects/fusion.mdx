Freelance web app for a Discord ticket / crypto-fiat exchange bot. Staff sign in with Discord OAuth, pick a guild, and configure panels, rates, users, and logging without editing bot config by hand.

## Highlights

- better-auth Discord OAuth; per-guild RBAC (Admin / Moderator / Spectator) on Server Actions and UI gates
- Six ticket panel types (exchange, MM, support, donate, apply, cash) with behavior, embeds, Discord-role permissions, automation
- Live Discord embed editor with Skyra preview + MDX; range-based FX rates and fees
- Prisma Client extension that writes audit logs on guild/config/backup writes; nested JSON diff viewer
- TanStack Query hydration from App Router; Dockerized Node 22 deploy

## Honest scope

Dashboard only — ticket execution lives in the bot repo. No tests/CI in-repo; some landing metrics are placeholders. Schema shares wallet/tax models the web app does not use.
