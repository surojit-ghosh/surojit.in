Public OSS learning project: paste a URL (+ optional timestamps) → Go Fiber API shells out to **yt-dlp** and **ffmpeg** → temporary download link. Built to help others read a small real Go HTTP service.

## Highlights

- Fiber API: platform routing, process orchestration, temp file cleanup via goroutines
- ffmpeg `-c copy` trim (start-only / end-only / both / full copy)
- Next.js 15 form with Zod + React Hook Form validation; Docker Compose split stack
- Production cookie-path handling for yt-dlp bot checks

## Honest scope

YouTube path is complete. Instagram / X return HTTP 501 stubs; Facebook is UI-only. No auth, DB, or signup — by design. README still marks active development.
