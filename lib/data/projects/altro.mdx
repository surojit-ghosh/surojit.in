Freelance full-stack build for **Altro UX Studio LLC** — a CMS-driven studio site (projects, portfolio media, pricing, reviews, Terms of Service) with admin at `/admin`.

## Highlights

- Payload CMS 3 inside Next.js 15; MongoDB collections + Lexical TOS global
- RSC loaders with `unstable_cache` and tag revalidation on admin writes
- UploadThing media CDN; portfolio cards that autoplay muted video vs still images
- Motion layout modals for project/portfolio expand; Discord-first conversion CTAs
- GitHub Actions CI running production `next build` with CMS/storage secrets
