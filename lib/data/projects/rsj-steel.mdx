Internship at **Cyber Peak** — implemented the public site for **RSJ Traders & Fabricators** (Kolkata steel stockist) end to end: catalog, grades, contact/RFQ, privacy, SEO.

## Highlights

- Next.js App Router static catalog (15 SKUs) + IS/ASTM mechanical/chemical spec matrices
- SEO system: Metadata API, canonicals, staging-safe robots, XML sitemap, Organization/Product/Breadcrumb JSON-LD
- Dynamic OG images via `next/og`; env-gated GA4 / Search Console hooks
- Client-side RFQ with Zod + React Hook Form → pre-filled WhatsApp message (no fake server receipt)
- Industrial design system (Tailwind v4, shadcn/Base UI) + IntersectionObserver motion with reduced-motion support

## Honest scope

Marketing/brochure site — no custom API, DB, or auth. Frontend + SEO slice of the internship; PRs merged by the team lead.
